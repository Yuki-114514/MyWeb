这个小站是用 [Astro](https://astro.build) 搭的。折腾过 Next.js、也写过纯手工 HTML 之后，个人网站这种场景，我最后还是回到了 Astro。

## 为什么是 Astro

一句话概括：**它默认几乎不发 JavaScript**。

个人站大部分内容是静态的——文章、项目介绍、关于页。这些东西根本不需要一个庞大的前端框架在浏览器里跑。Astro 把页面预渲染成纯 HTML，加载快得离谱。

```astro
---
// 这段代码只在构建时跑，不会进浏览器
const posts = await getCollection("blog");
---
<ul>
  {posts.map((post) => <li>{post.data.title}</li>)}
</ul>
```

需要交互的地方，再用「岛屿」按需加一点点 JS 就好。该静的静，该动的动。

## 写博客像写日记

新增一篇文章，只要在 `content/blog/` 里丢一个 Markdown 文件，填好顶部的标题、日期、标签，保存——它就自动出现在博客列表里了。

- 不用碰数据库
- 不用管路由
- 文件名就是网址

对于「想写就写」的个人博客来说，这种轻松感太重要了。

## 一点小结

技术选型没有标准答案，但如果你也想要一个**快、省心、还能长期维护**的个人站，Astro 真的值得试试。

反正我，是被它圈粉了。🌟
